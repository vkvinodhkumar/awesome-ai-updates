# AI Terminology

Last Updated: 2026-08-18 00:44:08

*   **Inference:** The stage where a trained AI model actually processes an input and generates an output (e.g., answering a question).
*   **Tokens:** The basic units of text (usually 3-4 letters) that an AI model processes. "750 tokens per second" is roughly 500-600 words per second.
*   **Embeddings:** A way of representing data (words, images, or locations) as a series of numbers so that the AI can understand the relationships between them.
*   **Agent:** An AI system designed to use tools and make decisions to achieve a specific goal autonomously, rather than just generating text.
*   **GPU Utilization:** A metric showing how much of a Graphics Processing Unit's power is actually being used; higher utilization means less money wasted on idle hardware.
*   **Open Model:** An AI model whose code or weights are available to the public, allowing anyone to run or modify it.
