# AI Terminology

Last Updated: 2026-08-13 10:56:12

* **Agentic AI:** AI systems designed to work autonomously, planning and executing multi-step tasks toward a specific goal without continuous human prompting.
* **Embeddings:** Numerical representations of data (like text, images, or geographic features) that help computers understand how different concepts or physical assets relate to one another.
* **Edge AI:** Running AI algorithms locally on physical devices (like a smartphone, robot, or camera) instead of processing the data in a remote cloud data center.
* **Knowledge Distillation:** A machine learning technique where a small, efficient model (the "student") is trained to mimic the behavior and intelligence of a massive, expensive model (the "teacher").
* **Tokens:** The basic units of information (chunks of words or code characters) processed by an AI model. More tokens translate to higher computational time and cloud costs.
* **TTS (Text-to-Speech):** AI technology that synthesizes written text into natural, human-sounding spoken voice.
* **Liquid Foundation Model (LFM):** A non-traditional neural network design optimized for processing sequential, real-time data efficiently while using less computational memory.
