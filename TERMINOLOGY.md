# AI Terminology

Last Updated: 2026-08-21 06:31:49

- **Zero Data Retention (ZDR):** A privacy setting where the AI provider does not store any of the data sent to the model after the request is processed.
- **Inference:** The process of an AI model "thinking" or generating an answer once it has already been trained.
- **GPT-5.6 Luna:** A specific, high-efficiency version of the GPT-5 model family optimized for coding and free-tier access.
- **GPU Utilization:** A measure of how much of a computer chip's processing power is actually being used at any given time.
- **Late Interaction (Multi-Vector):** A technique that allows an AI to compare a search query to a document word-by-word at the very end of the process, leading to much more accurate results than traditional search.
- **Private Safety Processing:** A method that allows AI safety filters to run on data without the data ever being stored or "seen" by the service provider's permanent logs.
