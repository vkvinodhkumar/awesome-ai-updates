# AI Terminology

Last Updated: 2026-09-27 14:44:42

*   **GPT-6 Astra:** A high-level, context-aware artificial intelligence model capable of processing complex information more effectively than previous iterations.
*   **Vision-Language Models (VLMs):** AI systems that can "see" and interpret visual data (images/video) alongside processing text.
*   **Quantization (Quants):** A process that shrinks an AI model's file size, allowing it to run on less powerful computers while maintaining most of its intelligence.
*   **Benchmarks:** Standardized tests used to measure how well an AI performs on specific tasks compared to other models.
*   **MLX:** An Apple-specific framework designed to make machine learning models run extremely fast on Macs and iPhones.
