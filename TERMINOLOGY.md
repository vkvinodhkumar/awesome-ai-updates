# AI Terminology

Last Updated: 2026-08-05 13:47:34

*   **Turnless Speech:** A voice interaction mode where the AI can listen and speak simultaneously, allowing for interruptions and more natural pacing.
*   **ARPU (Average Revenue Per User):** A metric used primarily by consumer-facing businesses to measure the revenue generated per subscriber.
*   **LFM (Liquid Foundation Model):** A type of AI architecture designed to be more computationally efficient than traditional Transformers, particularly good at handling sequential data.
*   **Geospatial Inference:** The process of using AI to analyze and make predictions based on geographic or satellite data.
*   **Agent Intrusion:** A cybersecurity event where an autonomous AI agent is used (either intentionally or via exploitation) to breach a secure network.
*   **Codex:** An OpenAI model specifically fine-tuned for programming and code generation tasks.
