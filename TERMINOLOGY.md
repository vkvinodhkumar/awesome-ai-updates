# AI Terminology

Last Updated: 2026-11-03 15:18:03

- **Codex:** An OpenAI model specifically designed to understand and generate computer code.
- **Git-Compatible:** A system that works with "Git," the world’s most popular version control tool for tracking changes in code.
- **Red-Teaming:** A security exercise where "ethical hackers" attack a system to find its weaknesses.
- **Bug Bounty:** A program that pays independent researchers money for finding and reporting security flaws.
- **Model Integration Contract (MIC):** A standardized set of rules that ensures a new AI model can "talk" to existing software libraries.
- **Transformers Library:** The most popular open-source collection of tools used to download and run AI models.
