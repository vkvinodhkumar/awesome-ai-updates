# AI Terminology

Last Updated: 2026-10-07 15:37:38

- **Agentic Workflow:** A process where an AI is given a goal and can independently perform multiple steps, use tools, and make decisions to finish it.
- **Computer Use:** AI capability that allows a model to operate a computer by clicking, typing, and navigating applications like a human.
- **Frontier Models:** The most powerful, state-of-the-art AI models currently available.
- **Lean:** A programming language used specifically to write and verify mathematical proofs.
- **Provenance:** The documentation of the origin of a piece of digital content; in AI, knowing if text or media was generated by a machine.
- **Synthetic Data:** Data that is created by AI models rather than collected from human behavior, used to train or refine other models.
- **TTS (Text-to-Speech):** Technology that converts written text into human-like audio.
