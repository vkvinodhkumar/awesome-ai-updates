## Technology Trends
*   **Agentic Workflows:** AI that can use tools, browse the web, and execute tasks autonomously.
*   **Edge Intelligence:** Moving AI processing from giant data centers to local devices (phones/PCs).
*   **Generative Simulation:** Using AI to create "digital twins" or virtual worlds for training robots and medical devices.

## Terminology
*   **Astra:** A code name for OpenAI’s advanced AI agent capable of multi-modal reasoning (seeing and hearing in real-time).
*   **GPT-5.6 Sol/Luna:** The newest iterations of OpenAI’s language models; "Sol" is likely the high-performance version, while "Luna" is the lightweight, faster version.
*   **LFM (Liquid Foundation Model):** A type of AI model that is more flexible and efficient at processing data over time compared to traditional models.
*   **Inference Provider:** A service that hosts an AI model so that others can use it via the internet.
*   **GPU (Graphics Processing Unit):** The specialized computer chips required to train and run AI.
*   **Edge AI:** AI that runs directly on your local device (like a phone or laptop) rather than on a remote server.
